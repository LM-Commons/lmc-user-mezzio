# Lmc User management for Mezzio

This components provides user management functionality for Mezzio applications

## Requirements

- PHP 8.3 or higher

## Installation

You can install the LMC User Mezzio library with composer:

```sh
$ php composer.phar require lm-commons/lmc-user-mezzio
```
